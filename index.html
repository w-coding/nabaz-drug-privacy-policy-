Last updated: January 31, 2026

Nabaz Drug Dictionary does not collect, store, or process any personal or non-personal user data.

The application does not request any permissions from the user’s device.

All features function without accessing:

  • Location

This app does not use any third-party services, SDKs, or libraries that collect or transmit user data.

Since no data is collected, no data is stored locally or on external servers.

Nabaz Drug Dictionary is safe for all age groups. The app does not knowingly collect any information from children or adults.

6. Security

Because the app does not collect or share data, there are no data security risks related to personal information.
